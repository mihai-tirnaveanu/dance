# Dansuri

Aplicație web pentru clipurile mele de salsa, bachata și kizomba: categorii și subcategorii, favorite, ordine schimbată prin drag & drop, sortare rapidă și un player cu viteză redusă, oglindă și repetare.

**Deschide aplicația:** https://mihai-tirnaveanu.github.io/dance/

Clipurile și categoriile stau în repo-ul privat `dance-video`. Aplicația le citește prin API-ul GitHub, cu un token salvat doar pe dispozitivul tău. Codul din acest repo nu conține date personale.

Fișiere: `index.html` (pagina), `app.css` (stiluri), `js/` (logica), `sw.js` (funcționare offline), `manifest.webmanifest` (instalare pe ecranul principal).
